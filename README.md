# לוח שליטה טקטי - חפ"ק

תמונה מבצעית לחפ"ק: לו"ז ושעוני יעד, אירועים, כוחות, כוחות חבירים, צירים, תמונת מצב חניונים ויומן מבצעים.

**המערכת היא קובץ HTML אחד וסגור.** פותחים אותו בלחיצה כפולה והוא עובד בדפדפן, בלי התקנה, בלי שרת ובלי אינטרנט.

> כל הנתונים בפרויקט הם נתוני הדגמה בדויים.

## שימוש

1. שומרים את `חפק-לוח-שליטה.html` במחשב ופותחים אותו בלחיצה כפולה. עובד ב-Chrome וב-Edge.
2. עורכים הכל ישירות במערכת: לחיצה כפולה על שורה או כרטיס, או לחיצה על "+" להוספה.
3. **גיבוי:** בסרגל העליון, כפתור ההורדה שומר את כל הנתונים לקובץ `hq-backup-<תאריך>.json`. כפתור ההעלאה משחזר מגיבוי ומחליף את הנתונים הנוכחיים (אחרי אישור). כך גם מעבירים נתונים למחשב אחר.

### חשוב לדעת

- **עמדה אחת.** כל מחשב שפותח את הקובץ עובד על עותק נפרד משלו. אין סנכרון בין מחשבים.
- **הנתונים נשמרים בדפדפן של המחשב, לא בתוך הקובץ.** לכן שליחת הקובץ למישהו לא שולחת לו את הנתונים שלך. ניקוי נתוני הגלישה מוחק אותם, וגם דפדפן אחר או חלון גלישה בסתר מתחילים נקי. **לייצא גיבוי בסוף כל משמרת.**
- **האחסון בדפדפן מוגבל** (כ-5MB). נשמרות 5,000 רשומות היומן האחרונות. אם השמירה נכשלת מופיעה הודעה, ויש לייצא גיבוי מיד.
- **אין תקשורת החוצה.** מדיניות האבטחה של הדף (CSP) חוסמת כל בקשת רשת, כך שהנתונים לא יכולים לצאת מהמחשב.
- **ההגנה היא על המחשב.** אין קוד כניסה, והנתונים בדפדפן לא מוצפנים. מי שיושב מול המחשב רואה אותם, לכן מחשב עם סיסמה ונעילת מסך.

## איך זה בנוי

```
 ממשק (React) ─→ מנוע (src/engine) ─→ אחסון הדפדפן (localStorage)
```

- **המנוע** (`src/engine/core.ts`) הוא מקור האמת. כל פעולה, למשל "פתיחת אירוע", נבדקת בו, מקבלת מספר ונרשמת ביומן עם השעה.
- **אחסון:** `browserDb.ts` שומר הכל כמסמך JSON אחד. אותו מבנה משמש גם כקובץ הגיבוי.
- **שדרוג נתונים:** כשמבנה הנתונים משתנה, נתונים קיימים מתעדכנים אוטומטית בפתיחה הבאה ושום דבר לא נמחק. כך למשל התווספו החניונים במקום התראות ה-LPR.

## פיתוח ובנייה

```bash
npm install
npm run dev      # שרת פיתוח עם רענון חי: http://localhost:5173
npm run build    # יוצר את הקובץ: dist/חפק-לוח-שליטה.html
```

הבנייה מכניסה את כל הקוד והעיצוב לתוך קובץ ה-HTML. היא נכשלת אם נשאר משהו חיצוני או אם חסרה מדיניות חסימת הרשת.

הקובץ נבנה גם בכל ריצת CI. אפשר להוריד אותו מדף הריצה ב-GitHub Actions, תחת Artifacts ← `hq-dashboard-file`.

## בדיקות

```bash
npm test          # כל הבדיקות: מנוע, אחסון, גיבוי וממשק
npm run typecheck # בדיקת טיפוסים לקוד ולבדיקות
```

ה-CI ב-GitHub Actions מריץ בדיקת טיפוסים, בדיקות ובנייה על כל PR.
